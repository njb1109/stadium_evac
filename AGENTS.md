## Project layout

Keep GitHub Pages entry files at the top level:

- `index.html` is the single-file web app entry point.
- `AGENTS.md`, `spec.md`, and `prompts.md` also remain at the top level.

Use numbered folders for all other project files:

- `00_planning/` for notes, sketches, diagrams, and planning drafts.
- `01_data/` for data files and datasets.
- `02_validation/` for hand calculations, test cases, and validation records.
- `03_output/` for screenshots, exported results, plots, and generated outputs.

## File placement

Save every new project file in the most appropriate folder. Do not add additional files to the project root except for GitHub Pages or project-level documentation.
